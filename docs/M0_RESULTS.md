# M0 사전 검증 결과 (요약본)

확인일: 2026-09-17. 핵심 3개 통과. KRX Open API 호출 누계 약 37회(401 포함).

이 문서는 저장소 커밋용 요약본이다. 약관 제11조②(제3자 제공 금지)와 불변 규칙 25에 따라 **KRX 응답의 원시 시세·거래량·시가총액·상장주식수 값은 싣지 않고**, 판정·필드 구조·도출 계수·비율만 기록한다. 원시 값이 포함된 전체본은 로컬 `data/notes/m0-results-full.md`(git 무시)에 있고, 응답 원문은 `data/raw/{service}/{basDd}.json`에 있다.

## 응답 필드

- 일별매매정보(유가·코스닥 동일, 15개): `BAS_DD, ISU_CD, ISU_NM, MKT_NM, SECT_TP_NM, TDD_CLSPRC, CMPPREVDD_PRC, FLUC_RT, TDD_OPNPRC, TDD_HGPRC, TDD_LWPRC, ACC_TRDVOL, ACC_TRDVAL, MKTCAP, LIST_SHRS`
  - `FLUC_TP_CD` 없음, 상한가·하한가 필드 없음
  - 명세 SQL: `CMPPREVDD_PRC = TDD_CLSPRC − BAS_PRC`, `FLUC_RT = ROUND((TDD_CLSPRC / BAS_PRC − 1) × 100, 2)`
  - `ISU_CD`는 단축코드 6자리
  - 유가증권 `SECT_TP_NM`은 명세 기본값 `-`가 아니라 빈 문자열
- 종목기본정보(유가·코스닥 동일, 12개): `ISU_CD(표준코드 12자리), ISU_SRT_CD, ISU_NM, ISU_ABBRV, ISU_ENG_NM, LIST_DD, MKT_TP_NM, SECUGRP_NM, SECT_TP_NM, KIND_STKCERT_TP_NM, PARVAL, LIST_SHRS` → 조인 키 `ISU_SRT_CD ↔ 일별매매 ISU_CD`
- KOSPI 시리즈 일별시세정보(12개): `BAS_DD, IDX_CLSS, IDX_NM, CLSPRC_IDX, CMPPREVDD_IDX, FLUC_RT, OPNPRC_IDX, HGPRC_IDX, LWPRC_IDX, ACC_TRDVOL, ACC_TRDVAL, MKTCAP`. **지수 코드 필드 없음**, 기준일당 48행
- 실측 행 수 규모(20180504): 유가증권 약 900행, 코스닥 약 1,270행

## 1. 기준가 역산 보정식 (핵심)

- 결과: `(종가 − 대비) / 전일 종가` = **0.020000 (1/50)**. 전일 종가를 정지일(05-03) 또는 마지막 거래일(04-27)로 잡아도 동일
  - 분할일 `LIST_SHRS` 변화율 = **정확히 50배** → 상장주식수는 **시점별 값**(`MKTCAP`도 시점별)

- 판정: **통과**
