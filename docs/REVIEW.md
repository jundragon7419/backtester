# KRX Backtester 청사진 최종 검증 및 근거 요약

검토 대상: `BLUEPRINT.md` (최종본)
이 문서의 용도: 청사진을 처음 보는 검토자가 **각 설계 결정이 무엇에 근거하는지**, **어떤 대안을 왜 기각했는지**, **무엇이 아직 확인되지 않았는지**를 확인하기 위한 자료.

## 1. 최종 자체 적대적 검증 결과

외부 검증 7회 이후 청사진 전문을 다시 검토해 찾은 결함과 조치. 모두 청사진에 반영 완료.

| # | 위치 | 결함 | 심각도 | 조치 |
|---|---|---|---|---|
| 1 | P5 시가 단계 | 체결(4단계) 안에서 비용을 반영한다고 하면서 5·6단계에서 슬리피지·수수료를 다시 차감. 현금 검사가 최종 비용 확정 전에 실행되어 음수 현금을 놓칠 수 있음 | 중 | 체결 절차를 하위 5단계로 정리하고 비용은 체결 시점에 즉시 확정, 현금 검사는 모든 비용 확정 후 |

### 1.1 최종 외부 검토 반영 (상급 4건, 데이터 2건, 근거 표현 5건, 자체 추가 1건)

|---|---|---|---|
| 7 | P2·P5 `rights` | 유상증자에 주식 수를 `1/계수`배로 늘려, 권리락 순간 가치는 보존되지만 이후 익스포저가 커짐 | 주식 수 유지, `주당 권리 가치(전일 종가 − 기준가) × 보유 주식 수`를 현금 지급. 1층은 `(1 − 계수)` 비율을 현금 비중으로 이전 |
| 8 | P4 비중 | 매매 종목만 목표 비중으로 교체해 기존 표류 비중과 합이 100%를 넘을 수 있음. 2층은 현금 한도로 막으므로 층간 투자 비중이 다름 | 현금 비중 명시, `Σ 비중 + 현금 = 1`, 매수 의도 비례 축소 |

### 1.2 최종 반영 점검에서 고친 파일 내부 불일치

피드백 항목 누락은 없었으나, 여러 차례 부분 수정하면서 생긴 불일치를 고침.

| 위치 | 불일치 | 조치 |
|---|---|---|
| P2·P4 | 1층은 `rights`·`unverified` 계수가 반영된 보정 가격으로 수익률을 계산하는데 2층은 주식 수를 바꾸지 않음. 1층 현금 이전 비율 `(1 − 계수)`도 권리락일 시가가 기준가와 다르면 2층 지급액과 달라, 권리락일에 M5 부동소수점 일치가 깨짐 | 지표용 `adj_*`와 수익률용 `ret_*`(분할만 반영) 분리. 1층 현금 이전을 `(전일 종가 − 기준가) / 당일 시가` 비율로 바꿔 2층 금액과 일치. 테스트 `test_rights_layer_parity.py` 추가 |
| P4 | `unverified` 종목 신규 진입 제외가 2층에만 있어 두 층의 유니버스가 다름 | 1층과 불변 규칙에 동일하게 추가 |
| P5 장전 | "대기 주문도 같은 계수로 조정"이라 쓰고 곧바로 조정이 필요 없다고 설명 | `OrderIntent`는 조정 불필요로 정리 |
| 불변 규칙 3·4 | 가격 계열 분리와 권리 현금 지급이 반영되지 않음 | 문구 갱신 |
| P7 게이트 | 평균 보유 기간을 어느 결과에서 재는지 없음 | IS 2층 거래 로그 기준으로 명시 |
| 파이프라인 그림·범위표·P8·M6 | `screening holdout`, `Conservative DSR`, 판정 수 대비 통과 수, 장기 보유 게이트가 일부 위치에 빠짐 | 용어와 항목 통일 |

### 1.3 외부 검토 개선안 중 조정한 것

| 제안 | 조정 | 이유 |
|---|---|---|
| 구조 변경 시 "보수적 terminal valuation" 또는 재개 후 처리 | 재개일 가격으로 그대로 평가하는 보수적 방식 채택. 분할 전 가치를 현금으로 보전해주는 방식은 기각 | 사후 정보 없이는 인적분할과 거래정지 후 실제 폭락을 구분할 수 없음. 가치 보전 처리는 실제 손실을 숨겨 상향 편향을 만듦 |
| OOS에 alpha-spending 등 오류예산 도입 (A안) | 기각, screening holdout(B안) 채택 | 개인 프로젝트에서 통계 프레임워크가 본체를 잠식. 최종 확인은 전진 검증이 담당 |
| 배당을 1차에서 모델링 | 판정 게이트로 대체 | 배당락일·배당금 데이터 확보 공수가 큼. 단기 전략은 영향이 작고 장기 전략만 차단하면 틀린 판정은 막힘 |

### 1.4 M0 실측 결과 반영 검증 (수정안 18건)

M0 결과로 제출된 수정안 18건을 적대적으로 검증한 결과. 청사진 9장에 결과 요약, `docs/M0_RESULTS.md`에 원시 근거.

**그대로 수용 (12건)**: #3 정지 행 시가 0 결측 처리, #4 유가증권 관리종목 판별 불가, #5 `대비` 자체 부호, #6 정지 중 상장주식수 변화 분리, #7 역산 계수 기준 판정, #10 지수 코드 부재, #11 코드 체계·D+1 08시, #13 fixture 가짜 데이터, #14 출처 표기, #16 교차검증 환경, #17 Python 3.13, #18 문서 갱신

**조정해서 수용 (6건)**

| 수정안 | 문제 | 조정 |
|---|---|---|
| #1 정지 후 재개는 `rights`에서 제외 | 수정안만 반영하면 **정지 후 발생하는 액면분할(삼성전자 2018)도 `restructure`로 빠짐**. 또 무상증자 30%(계수 약 0.769)와 대한항공 유상증자(0.7754)처럼 정지 없는 경우도 계수만으로 구분 불가 | 분류 순서를 ① 정지 후 + 분할 비율 + 주식수 일치 → `share_change` ② 정지 후 나머지 → `restructure` ③ 정지 없는 하락 → `rights` ④ 그 외 `unverified`로 재설계. 무상증자는 `rights`로 흡수(가치 보존, 공짜 주식 방지) |
| #2 `unverified`와 `restructure` 우선순위 | 우선순위 표만 추가하면 SK텔레콤 같은 실제 인적분할은 어느 쪽이든 틀리게 처리됨 | #1의 순서로 중복이 사라짐. 인적분할은 **수작업 자본변동 표**(DART 공시 비율, 공시일을 `known_date`로)로 처리하고, 유니버스 후보 내 전 건 등록을 M2 완료 조건으로 둠 |
| #8 `tick_rules` 확정, 배수 위반 0건으로 간접 검증 | 구간표를 같은 가격 데이터에서 역산했으므로 배수 위반 0건은 **순환 검증** | 공식 조문 확정을 M2 완료 조건으로 두고, 배수 검사는 확정 후에만 적용 |
| #9 정리매매 제한폭 예외 | 신규상장일 등 다른 제한폭 비적용일도 응답으로 식별 불가. 품질 검사 예외만으로는 2층 상하한가 판정 오류가 남음 | 등락률이 제한폭을 넘는 행을 `limit_exempt`로 표시하고 그날은 상하한가 판정 자체를 하지 않음 |
| #12 초기 적재 5개 서비스 × 4,100일 | 종목기본정보는 종목명·증권구분 보조용이라 **매일 호출할 필요가 없음** | 신규 코드 등장일에만 호출. 약 12,300회 + 등장일 수로 2~3일 |
| #15 SK텔레콤 보유 동결 손실 약 −43% | 청사진 규칙은 `restructure`에서 주식 수를 늘리지 않으므로 규칙대로면 약 −83%(계수 0.1725). −43%는 분할 5:1 주식 증가를 반영한 값이라 **현재 규칙의 편향을 과소 표시** | 리스크 표에 규칙 기준 수치로 기재하고, 수작업 표로 해소 |

## 2. 의도적으로 받아들인 근사

검토자가 "왜 이렇게 단순화했는가"를 물을 수 있는 항목. 모두 청사진 10장 리스크와 11장 확장 조건에 대응이 있다.

| 근사 | 실제와의 차이 | 받아들인 이유 |
|---|---|---|
| 성과는 가격 수익률(배당 미포함) | 장기 보유·고배당 전략 과소평가 | 장기 보유 전략은 P7 등록을 차단해 틀린 판정을 막음. 벤치마크도 가격지수로 맞춤 |
| 인적분할 등 구조 변경은 수작업 자본변동 표로 처리, 미등록 건만 보유 동결 후 재개 가격 평가 | 미등록 건은 신설 법인 지분과 분할 주식 증가분이 손실로 반영 (하향 편향) | 가격·주식수만으로 인적분할을 복원할 수 없음. 공시 비율을 쓰는 표는 인과성을 지키고, 미등록 건은 실제 폭락과 구분 불가하므로 보수적 방향 |
| 유상증자 권리락은 권리 가치 현금 지급 | 신주인수권 매매·청약 미반영 | 권리락 순간 가치 보존과 이후 익스포저 불변을 동시에 만족하는 최소 모델 |
| 체결은 시가 단일가만 | 장중 체결 전략 표현 불가 | 일봉 데이터로 장중 가격 경로를 알 수 없음 |
| 상하한가 체결은 비율 파라미터 1개 | 실제 단일가 수량 배분 규칙 미반영 | 시가총액 상위 유니버스에서 해당 거래가 드묾. 민감도 분석으로 영향 확인 |
| DSR은 원시 시도 수 기준 (`Conservative DSR`로 표시) | DSR은 독립 시도 수를 전제하므로 상관된 조합에 원시 개수를 넣으면 과하게 할인 | 틀린 것이 아니라 의도적으로 보수적인 근사. 유효 시도 수는 2차 |
| 1층은 정수 주·상하한가·참여율 충격·정지 중 이월 무시 | 1층 성과가 2층보다 낙관적 | 대량 탐색 처리량 확보. 주문 의도와 현금 한도는 공유하므로 차이는 체결에서만 발생. 층간 괴리를 지표로 표시 |
| OOS는 screening holdout | 다중검정 보정 없음 | 통과를 검증 완료로 해석하지 않고, 판정 수 대비 통과 수를 표시. 최종 확인은 전진 검증 |

| JSON 스키마와 전략 해시 | [설계] 실행 식별과 재현성, 키움 프로그램과의 공유 |

### 3.3 엔진 (P4, P5)

| 결정 | 근거 |
|---|---|
| 1층 벡터화 스크리너 + 2층 event-driven 검증기 | [설계] 탐색 처리량과 체결 현실성의 분리. 학술 근거 없음. 신호와 `OrderIntent`를 공유하고 제약을 끄면 부동소수점 수준으로 일치해야 한다는 M5 기준으로 정합성을 보증 |
| t일 종가 신호, t+1일 시가 체결 | [설계·학술] look-ahead bias 방지의 표준 관행 |
| 가격 계열 분리: 지표용 `adj_*`(분할·권리락 반영), 1층 수익률용 `ret_*`(분할만 반영), 2층은 원시 가격 + 잔고 재조정 | [설계] 권리락은 지표에서는 가짜 하락 신호를 막아야 하지만, 수익률에서는 2층처럼 주식 수 불변 + 현금 지급으로 처리해야 두 층의 금액이 일치 |
| 공통 `OrderIntent` (매도 비율, 매수 목표 금액) | [설계] 분할일 직전 주문의 수량 불일치 방지와 층간 주문 정의 일치 |
| 1층 현금 비중과 `Σ 비중 + 현금 = 1` | [설계] 회계 무결성. 1층의 암묵적 레버리지 방지 |
| 이벤트 `known_date` 인과성 규칙 | [설계·학술 배경] look-ahead 방지. 부정적 상장폐지가 상당 부분 예상 밖 사건이라는 Shumway (1997)의 문제의식은 사후 정보로 폐지 처리를 하면 안 된다는 방향을 지지하나, 미국 CRSP 연구이므로 한국 제도를 직접 증명하지는 않음 |
| 슬리피지 = 기본 bps + 계수 × √참여율 | **[문헌 기반 설계 근사]** 시장 충격의 준선형 규모 의존성을 참고한 휴리스틱. Tóth et al. (2011)은 제곱근 법칙을 경험적으로 지지하나, Almgren et al. (2005)은 자신들의 표본에서 일시 충격의 제곱근 모델을 기각하고 약 3/5승을 선호함. 한국 시장 자료로 보정되지 않았으므로 민감도 분석 대상. 실제 기관 거래 비용: Frazzini, Israel & Moskowitz (2018, working paper) |
| 참여율 분모는 t일까지의 ADV20 | [설계] 체결일 거래량은 시가 시점에 알 수 없으므로 look-ahead 방지. 외부 검증 제안(t+1일 거래량)을 이 이유로 기각 |
| 거래비용이 이상현상 수익을 크게 잠식함 | [학술] Novy-Marx & Velikov (2016), 고회전 이상현상의 순수익이 비용 반영 후 크게 감소 (서지 확인 필요) |
| 시가 체결에 호가 단위 1틱 비용을 강제하지 않음 | **[설계]** 단일가 매매는 하나의 가격에서 체결되어 스프레드 교차가 없다는 판단. 주기적 단일가 경매의 미시구조 배경은 Madhavan (1992)이나, 이 논문이 비용 모델 결론을 직접 입증하지는 않음 |
| 매수 수량에 비용 선반영, 현금 음수 금지 | [설계] 회계 무결성. 가짜 레버리지 방지 |
| 비용은 매수·매도 비대칭, 거래세는 매도에만 | [공식] 증권거래세는 양도(매도) 시 부과 |

### 3.4 연구 통제 (P6, P7, 실험 기록)

| 결정 | 근거 |
|---|---|
| 모든 시도를 조합 단위로 기록 | [학술] 데이터 스누핑 편향: Lo & MacKinlay (1990); White (2000) Reality Check. 다중 검정 기준 상향: Harvey, Liu & Zhu (2016) (서지 확인 필요) |
| Conservative DSR | [학술] Bailey & López de Prado (2014). DSR은 독립 시도 수를 전제하고 종속 시도에서는 독립 시도 수 추정을 별도로 논의함. 원시 조합 수를 넣는 본 구현은 의도적으로 보수적인 근사 |
| 백테스트 과적합 경고, 파라미터 안정성 확인 | [학술] Bailey, Borwein, López de Prado & Zhu (2014, 2017), 시도 수가 늘수록 IS 최적 전략의 OOS 성과가 악화될 확률 증가 (서지 확인 필요) |
| OOS는 screening holdout: 통과·탈락만, 결과 간 비교 금지, 통과를 검증으로 해석하지 않음 | [학술] OOS 결과로 전략을 고르면 선택 편향이 OOS로 이전됨: López de Prado (2018). 동일 데이터 반복 사용의 스누핑: White (2000). 다중 가설의 유의성 기준: Harvey, Liu & Zhu (2016). 개봉 한도는 노출 통제일 뿐 오류율 보정이 아님을 명시 |
| 통과 기준 사전 등록 | [학술] 금융경제학 연구의 사전 등록·다중 검정 보정 권고: Harvey (2017) (서지 확인 필요) |
| 3-way split을 채택하지 않음 | [설계·학술 배경] 약 16년 데이터를 셋으로 나누면 각 구간이 단일 시장 국면만 포함. 단순 holdout만으로 과적합이 해결되지 않는다는 점은 Bailey et al. (2017) PBO 문헌과 부합. "한 번도 열지 않은 테스트"는 전진 검증이 담당 |
| 스트레스 설정은 사전 등록 후 한 번의 개봉에서 실행 | [설계] 사후 비용 설정 변경 재실행을 허용하면 탈락 전략을 유리한 설정으로 통과시키는 경로가 생김 |
| 손익분기 비용 = 비용 차감 전 초과수익 ÷ 회전율 | [설계] 비용이 회전율에 선형 비례한다는 1층 비용 모델에서 도출. 참여율 충격이 큰 전략에서는 근사 |

## 4. 외부 검증에서 기각한 제안

재검토 시 같은 제안이 반복되지 않도록 기록.

| 제안 | 기각 사유 |
|---|---|
| OOS 오류예산(alpha-spending) 도입 | 프로젝트 규모 대비 과잉. screening holdout으로 의미를 낮추고 전진 검증을 최종 확인으로 둠 |
| 구조 변경 종목의 분할 전 가치를 현금으로 보전 | 사후 정보 없이 인적분할과 실제 폭락을 구분할 수 없어 실제 손실을 숨김 |
| 기준가 역산 폐기, DART를 수정주가 주 원천으로 | DART 구조화 API에 액면분할이 없음. 기준가 역산은 가격 급변과 무관하게 기준가 조정일에만 반응. 인용된 Fama & French (1992)는 수정주가 방법론 문헌이 아님 |
| t+1일 거래량 기준 슬리피지 페널티 | 체결 시점에 알 수 없는 정보 사용 (look-ahead) |
| 시도 Sharpe의 평균·표준편차만 저장 | 유효 시도 수 추정이 불가능. 조합별 일별 수익률 저장으로 대체 |
| KRX가 현금배당락일에 기준가를 조정한다는 전제의 보정 요구 | 1998년 폐지된 제도 |
| 상하한가 시 당일 거래량의 1–5% 부분 체결 | 일봉으로 단일가 체결량 분리 불가, 비율에 근거 없음, 편향 방향이 매수·매도에 따라 반대 |
| `name`·`type` 기준 전략 계열 단위 OOS 통제 | 이름 변경으로 우회 가능 |
| 3-way split (Train/Validation/Test) | 데이터 기간 부족. 전진 검증이 최종 테스트 역할 |
| 호가 잔량 비례 대체 슬리피지 | 일봉에 호가 잔량 없음 |
| 슬리피지 후 체결가를 1호가 올림·내림 | 시가 단일가매매에는 스프레드 교차 비용이 없어 비용 과대평가 |
| 비용 설정만 바꾼 OOS 재실행을 예산 면제 | 판정 우회 경로. 사전 등록한 스트레스 설정으로 대체 |
| P5 자산 평가를 시가로 통일 | MDD·변동성·벤치마크 비교는 종가 기준이 표준. 시가·종가 스냅샷 병행으로 대체 |
| KRX 원시 상하한가 필드 사용 후 계산 로직 삭제 | 서드파티 문서의 응답 필드 목록에 해당 필드가 없음. M0 확인 후 조건부 전환으로 반영 |

## 5. 검토자에게 요청하는 점검 항목

작성자가 스스로 판단하기 어렵거나 확인하지 못한 부분.

1. **M0 핵심 3개는 통과**(기준가 역산 1/50, 부호 있는 `대비`, 폐지 종목 포함). 남은 확인 대기는 호가 단위 공식 조문, 코스닥 관리종목 표기 지연 여부, 실패 호출의 한도 포함 여부, 지수명 변경 이력
2. **이벤트 분류 순서(청사진 P2-3 표)**: 정지 없는 무상증자를 `rights`로 흡수해 익스포저가 작아지는 편향을 받아들였는데 이 선택에 동의하는지
3. **수작업 자본변동 표의 범위**: 유니버스 후보(시가총액 상위 N) 안의 `restructure` 전 건 등록을 M2 조건으로 뒀는데, N을 얼마로 둘지
4. **장기 보유 게이트 임계값**: P7 등록을 막는 평균 보유 기간 기본값(20거래일)이 적절한지.
5. **OOS 구간 길이와 개봉 총량 한도의 초기값**: 청사진은 구조만 정했고 수치는 비어 있다.
6. **슬리피지 초기값**: 기본 bps, 충격 계수, 참여율 상한은 한국 시장 실측치 없이 가정으로 둔다. 키움 모의투자 체결 기록으로 사후 보정할 계획이다.
7. **수작업 표 미등록 `restructure`의 하향 편향**: 미등록 건은 보유 동결 후 재개가로 평가해 분할·신설 법인 몫이 손실로 기록됨(SK텔레콤 2021이면 약 −83%). 유니버스 후보 내 전 건 등록으로 막았지만, 유니버스 밖 종목이 탐색 중 편입되는 경우의 처리가 충분한지. 상장폐지는 스냅샷에서 사라진 날 인식해 직전 종가로 청산
8. **범위 판단**: "없으면 결과가 틀리는가"를 1차 포함 기준으로 썼다. 11장으로 미룬 항목 중 1차에 들어가야 할 것이 있는지.
